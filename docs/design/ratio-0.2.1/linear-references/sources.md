# Linear product interface references

Images published by Linear. The five source files preserve the original image bytes. The contact sheet combines four resized copies and adds labels. The border comparison below is provided separately at full resolution.

[Open the contact sheet](linear-ui-references.jpg)

## Code diff

Changed files sit to the left of the code. Each file has its own header and line numbers, with restrained red and green fills marking edits. A conversation panel sits at the right.

[code-diff.png](code-diff.png) · 3330 × 2194 pixels · [Reviews documentation](https://linear.app/docs/diffs) · [Original image](https://webassets.linear.app/images/ornj730p/production/e6108a650d6fd66011fbde5cbb8446ec2b46cd9a-3330x2194.png)

## Review inbox

Reviews are grouped by the attention they need. Each queue row shows its title and status, while the selected review’s code stays in the adjacent pane.

[review-inbox.png](review-inbox.png) · 3600 × 2200 pixels · [Linear Diffs changelog](https://linear.app/changelog/2026-05-27-linear-diffs) · [Original image](https://webassets.linear.app/images/ornj730p/production/3852f8c30d20c29a0831c1d6ca1682542c7b386e-3600x2200.png)

## Issue peek (2019)

The selected issue stays visible in the list while a floating card shows its title, properties, and description. Linear published this light-theme image in 2019.

[issue-peek.jpg](issue-peek.jpg) · 1700 × 846 pixels · [Improved peek changelog](https://linear.app/changelog/2019-09-23-improved-peek) · [Original image](https://webassets.linear.app/images/ornj730p/production/e3dd9890b2d3245e47679f2231fb9b776f9b4d61-1700x846.jpg)

## Navigation sidebar

Linear places the newer navigation on the right. A subtle filled row marks Inbox, while the surrounding navigation uses smaller icons, quieter inactive labels, and more vertical padding.
