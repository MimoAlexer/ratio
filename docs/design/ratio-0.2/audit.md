# Ratio v0.1.1 rendered design audit

The signed-in Home already answers an unusually valuable question for a solo developer. It identifies LU-32 “Rebuild stale backlinks,” gives the exact next action, links to the source note, and opens the issue. Preserve those relationships. The largest opportunities lie in the steps on either side of this moment. An empty workspace offers conflicting actions, a dense list sends the composer a long way from its trigger, and errors take the user out of their work.

## Evidence

The screenshots come from the actual server on port 4178. The populated account contains Luma, 19 issues and three notes. Two separate local QA accounts supply an empty workspace and a 25-issue long-title fixture. The populated capture blocks document writes and third-party requests. Browser preferences are isolated. All pictures are viewport captures at device scale factor 1 in Chromium. The mobile configuration enables touch. The browser emulates reduced motion. These checks establish Chromium appearance and behavior on the captured build. They do not establish assistive-technology speech output or native WebKit/Windows rendering.

## Where to inspect

Each viewport directory contains corresponding named PNGs. Start with home, issues, dense-issues, issue-new, form-invalid-issue, projects-detail, notes-detail, roadmap, and keyboard-help. The sheets directory groups ordinary pages, planning, account, interactive states and synthetic fixtures. The complete individual images preserve full text and original dimensions.

- metrics.json records each populated capture's route, viewport, first issue geometry, headings, scrolling regions, font styles and visible links. A link intersecting the viewport is counted even when partly visible.
- synthetic-report.json records fixture assertions, form HTTP outcomes, draft recovery, and screenshots. synthetic-findings.md records the form and first-use findings.
- keyboard-audit.json records browser accessibility trees, alternate theme, shortcut preferences, and no-script behavior. The separate a11y directory one level up contains focused color, keyboard, touch and zoom checks. Tiny targets and sampled colors in the general geometry metric are review candidates, not findings of WCAG nonconformance.

## Reproduction

From the workspace root, run the following command against a local development build with sample data and local development sign-in links enabled. Use a fresh destination for each cycle.

```sh
work/ratio-design/capture-phase.sh http://127.0.0.1:4178 work/ratio-design/cycles/phase-name full
```

The core mode captures Home, dense and empty states, list, detail, creation, focus, filters, projects, notes, roadmap, insights, settings, shortcuts and mobile navigation. The full mode adds auxiliary routes, interaction snapshots, and the alternate theme. Captures discover entity routes from the active account and use the current controls. If the presentation changes the accessible names or selectors of an interaction, the capture exits with its named failure so the adapter can be updated and rerun. Fixture sign-ins and state files stay outside evidence directories.
